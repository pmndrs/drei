A shader-based image component with auto-cover (similar to css/background: cover).

```tsx
export type ImageProps = Omit<ThreeElements['mesh'], 'scale'> & {
  segments?: number
  scale?: number | [number, number]
  color?: Color
  zoom?: number
  radius?: number
  grayscale?: number
  toneMapped?: boolean
  transparent?: boolean
  opacity?: number
  side?: THREE.Side
}
```

```jsx
function Foo() {
  const ref = useRef()
  useFrame(() => {
    ref.current.material.radius = ... // between 0 and 1
    ref.current.material.zoom = ... // 1 and higher
    ref.current.material.grayscale = ... // between 0 and 1
    ref.current.material.color.set(...) // mix-in color
  })
  return <Image ref={ref} url="/file.jpg" />
}
```

To make the material transparent:

```jsx
<Image url="/file.jpg" transparent opacity={0.5} />
```

You can have custom planes, for instance a rounded-corner plane. `Image` sizes the texture from the geometry's `parameters.width` and `parameters.height` and samples it with the geometry's UVs. `ShapeGeometry` uses vertex positions as UVs, so draw the outline in the unit square, then scale it.

```jsx
import * as THREE from 'three'
import { extend } from '@react-three/fiber'
import { Image } from '@react-three/drei'

class RoundedPlaneGeometry extends THREE.ShapeGeometry {
  constructor(width = 1, height = 1, radius = 0.1, segments = 8) {
    const rx = radius / width
    const ry = radius / height
    const shape = new THREE.Shape()
      .moveTo(0, ry)
      .lineTo(0, 1 - ry)
      .quadraticCurveTo(0, 1, rx, 1)
      .lineTo(1 - rx, 1)
      .quadraticCurveTo(1, 1, 1, 1 - ry)
      .lineTo(1, ry)
      .quadraticCurveTo(1, 0, 1 - rx, 0)
      .lineTo(rx, 0)
      .quadraticCurveTo(0, 0, 0, ry)
    super(shape, segments)
    this.translate(-0.5, -0.5, 0).scale(width, height, 1)
    this.parameters = { width, height, radius, segments }
  }
}

extend({ RoundedPlaneGeometry })

<Image url="/file.jpg">
  <roundedPlaneGeometry args={[1, 2, 0.15]} />
</Image>
```
